## Full Change List

- Desktop and mobile: **OpenCode Go** is now an AI provider option alongside OpenAI, Gemini, and Anthropic. Add its API key in AI settings and pick a model (defaults to `gpt-5.6-luna`); requests use the official OpenCode Go endpoint with a per-editor session so routing stays stable within one interaction. Keys stay on the device and never sync.
